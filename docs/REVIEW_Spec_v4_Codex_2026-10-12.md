# Codex review of MAIIC EIR Engine Specification v4

Date: 12 October 2026. Repository: `DupleixInstitute/MAICC-IFRS9`. Branch reviewed: `eir_revenue_recognition`, fetched head `ce154713998d1faf1a1d7ab5d053f56c879a470d`. Specification revision: `7bc97a540827a407e08f3446c05b2f6ebf773302`.

Read against `docs/REVIEW_BRIEF_Spec_v4_for_Codex_2026-10-12.md`. The specification was not edited. The review used a separate worktree because the existing checkout contains work in progress.

The fee and interest bridges provide a useful foundation, but the specification should be corrected before the new fee, write-off and reschedule rules become accounting entries. The most immediate implementation error is the rule that treats a drawdown as a fee merely because its batch credits a fee GL. The most material accounting issues are the automatic default rebuttal, the treatment of every manual rate change as a reset, and the use of contractual interest for an EIR result inside a month.

P1 means correct before the affected calculation is used in an official result. P2 means correct before the affected feature is accepted. Findings are review conclusions; suggested treatments remain proposals for the team's review. In particular, this report does not turn a Finance confirmation still outstanding into an Agreed decision.
